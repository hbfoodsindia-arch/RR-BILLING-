## Features
- Billing with GST and discount
- Product barcode/SKU, cost price, selling price and stock
- Automatic stock deduction on sales
- Purchase entries and stock increase
- Customer list and credit sales/dues
- Expense tracking
- Sales, purchase, expense and due reports
- JSON backup and restore
- Thermal-style printable invoice
- WhatsApp sharing can be added through the Android share sheet/browser
- Offline local storage

## Build
Open this folder in Android Studio and let Gradle sync. Then use:
Build > Build App Bundle(s) / APK(s) > Build APK(s)

The billing interface is bundled offline in `app/src/main/assets/index.html` and uses local browser storage for data.
